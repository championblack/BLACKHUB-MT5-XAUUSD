# BLACKHUB MT5 XAUUSD

Mobile-friendly educational dashboard for historical XAUUSDm candle analysis.

## Current features
- Import OHLC candles from CSV.
- Calculate EMA 20, EMA 50 and RSI 14.
- Display an educational trend readout and candle chart.

## Limitations and safety
This site does not connect to MetaTrader 5 or Exness, has no live price feed and cannot place orders. MT5 Android does not expose the desktop Python integration. Use historical demo-account data only. Never enter broker passwords, investor passwords or API keys here. Educational use only; not financial advice.
